# CivicWater Sentinel — Backend & Ingestion

Ingestion API and orchestration layer of **CivicWater Sentinel** (Team CodigoMaster,
IBM Z Datathon 2026): real-time water-leak detection on 5-minute SCADA windows from the
simulated BattLeDIM L-Town network, with auditable inference on IBM LinuxONE.

> Work in progress. See `docs/status.md` for the real state of the code.

## Data

No BattLeDIM / L-Town data is stored in this repository. The dataset is distributed by its
authors under their own terms; obtain it from the original source. The network is simulated:
nothing here is validated on a real distribution network.

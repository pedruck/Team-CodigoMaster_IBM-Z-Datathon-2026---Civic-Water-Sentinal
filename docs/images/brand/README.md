# Brand assets

The CivicWater Sentinel logo is **the dashboard's own brand lockup**, redrawn as plain SVG so it
can be used outside the dashboard (README, slides, posters). There was no logo file in the
repository before; nothing here is a new identity.

| File | Use |
|---|---|
| `logo.svg` | Lockup on light backgrounds (ink text). |
| `logo-dark.svg` | Lockup on dark backgrounds (light text). Pair both with `<picture>` to follow the reader's theme. |
| `logo-mark.svg` | The tile alone: avatar, favicon, small spaces. |
| `banner.svg` | 1280 × 420 hero for the README: the lockup, the tagline and the L-Town network. |
| `design-tokens.svg` | The dashboard's colour tokens by role, with the names of [`DESIGN.md`](../../../DESIGN.md). |

## Where it comes from

- **Mark and proportions:** `.brand` / `.brand-mark` in `dashboard/assets/theme.css`
  (a 36 × 40 tile, 6 px radius, Network Green `#08796f`; a 26 px white drop) and
  `render_sidebar` in `dashboard/presentation.py`.
- **Drop:** the regular "drop" glyph of Phosphor Icons 2.1.1 (MIT), the same file the dashboard
  bundles (`dashboard/assets/icons/drop.svg`).
- **Wordmark:** IBM Plex Sans (SIL OFL) from `dashboard/assets/fonts/`: "CivicWater" in SemiBold,
  "SENTINEL" in Medium with 0.25 em tracking. The text is converted to outlines with the fonts'
  own kerning, so the SVGs look the same wherever they are drawn, including GitHub's `<img>`
  sandbox, which cannot load fonts.
- **Banner backdrop:** `config/l-town-map.json`, the derived L-Town schematic (909 links, 33
  pressure sensors), network from BattLeDIM 2020 (Vrachimis et al.), CC BY 4.0.
- **Colours:** `DESIGN.md`. The banner uses Rail Teal for its ground and no coral: coral is
  reserved for alarms.
- **Tagline and cover composition:** the team pitch (`Finds small water leaks while they are still
  small.`).

The SVGs were generated by a throw-away script from those files; they are committed as outputs.
If a token in `DESIGN.md` changes, redraw them from the same sources rather than editing the
paths by hand.

## Rules

- Keep the clear space of half the tile's width around the lockup; do not recolour the tile.
- Do not use Alert Coral in or around the logo (DESIGN.md: "The Coral Is an Alarm Rule").
- The banner and the screenshots next to it show **simulated** data; keep that wording where they
  are used.
